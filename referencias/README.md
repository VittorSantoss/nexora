# Referências

Sites de referência visual/estrutural pra usar como inspiração na
criação de sites e landing pages pra clientes.

Coloca links, screenshots ou anotações aqui. Quando for pedir a
criação de um site novo, referencia o que tiver nessa pasta.

## Modelo padrão de demonstração

**[modelo-demonstracao-lp.html](modelo-demonstracao-lp.html)** — estrutura
fixa pra toda demonstração de site pedida daqui pra frente (base: a
demo feita pra Dra. Elisângela Paz). Toda vez que o pedido for "faz uma
demonstração de site" (uso em prospecção, antes de fechar), usar esse
arquivo como esqueleto: mesmas seções, mesmo fluxo de copy, mesma
estrutura de página. Só muda por cliente:

- Identidade visual (cores, tipografia, tom) — nunca a dark da Nexora
- Informações do cliente (nome, serviços, depoimentos, contato, fotos)

Isso é diferente da skill `/site-cliente` (que monta o site completo
pro cliente já fechado, hub + LP por serviço). O modelo aqui é só pra
demo de venda — uma página única.

  Corazza & Iezzoni, escritório em Salto/SP, 40 anos, civil/trabalhista/
  imobiliário/cível. Layout clean e minimalista, paleta neutra

  "tradição jurídica" + "visão contemporânea".
